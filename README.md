# AETHER Desktop

A custom anime/fantasy-inspired login and lockscreen
environment for Arch Linux and Hyprland.

## Components

- Custom SDDM theme using Qt Quick / QML
- Custom Hyprlock configuration
- Midnight blue and violet visual identity
- Animated login backgrounds
- Integrated login music player

## Development Status

Currently under development.

## Platform

- Arch Linux
- Hyprland
- SDDM
- Qt 6
- Hyprlock
